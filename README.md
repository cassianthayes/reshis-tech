# Прогноз продаж билетов

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Приложение доступно на http://127.0.0.1:8000. База и ключ сессий создаются сами.

Тесты: `.venv/bin/python -m unittest -v`.

Для разработки использовал Zed (агенты GPT-6.1-Sol), uv.
